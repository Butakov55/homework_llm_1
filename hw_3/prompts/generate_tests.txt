Ты — эксперт по тестированию API. Сгенерируй автотесты для API-сервиса с использованием Python 3, Pytest и Requests.

Базовый URL API: https://jsonplaceholder.typicode.com

Сгенерируй 3 тестовых файла с разными наборами тестов:

1. test_posts_api.py - тесты для работы с постами:
   - GET /posts - получение всех постов
   - POST /posts - создание нового поста
   - GET /posts/1 - получение конкретного поста
   - GET /posts?userId=1 - фильтрация постов

2. test_comments_api.py - тесты для работы с комментариями:
   - GET /posts/1/comments - получение комментариев поста
   - GET /comments - получение всех комментариев
   - Проверка структуры комментария

3. test_users_api.py - тесты для работы с пользователями:
   - GET /users - получение всех пользователей
   - GET /users/1 - получение конкретного пользователя
   - GET /users/1/posts - получение постов пользователя

Требования к тестам:
- Используй pytest с фикстурами для базового URL
- Проверяй HTTP статус коды (200, 201, 404)
- Проверяй структуру JSON ответа (обязательные поля)
- Используй parametrize для тестирования разных данных
- Добавь валидацию типов данных
- Сделай тесты независимыми друг от друга
- Добавь осмысленные сообщения об ошибках

Сгенерируй полный код для всех тестов с использованием лучших практик pytest.
Код должен быть готов к запуску без дополнительных изменений.
